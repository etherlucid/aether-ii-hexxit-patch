# Aether II Hexxit Patch

Bytecode patches to the Aether II 1.5.2 mod for Minecraft 1.5.2 (Hexxit Remix).

The `main` branch contains the original unpatched mod contents.
The `patched` branch contains the working patched version.
The `fix/creative-survival-inventory` branch contains the WIP fix for the Creative Survival Inventory layout.
